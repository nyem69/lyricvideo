# Lyric Studio — Landing i18n with Paraglide (en/ms/id) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the Lyric Studio **landing page** into English (`en`, base), Bahasa Melayu (`ms`), and Bahasa Indonesia (`id`) using **Paraglide JS v2 (`@inlang/paraglide-js`)** + the inlang message-format, matching the conventions in `nasab` / `manahalal-pwa`, with a compact header `LanguageSwitcher`, a client locale strategy (`localStorage` › `preferredLanguage` › `baseLocale`), and no product-UI changes.

**Architecture:** Paraglide compiles `messages/{en,ms,id}.json` to a tree-shaken `m.key()` API under `src/lib/paraglide/` (committed). Landing components call `m.*()`. The app is a global SPA (`ssr=false`); the switcher calls Paraglide `setLocale()` (persists to `localStorage` + reloads), so `m.*()` render in the chosen locale with no FOUC. No locale routes, no `reroute`, no server middleware (those are the deferred Path-A follow-up).

**Tech Stack:** SvelteKit 2 (adapter-static), Svelte 5 runes, TypeScript, Tailwind v4, Vitest, `@inlang/paraglide-js` v2, inlang message-format.

**Spec:** `docs/superpowers/specs/2026-06-08-lyric-studio-i18n-design.md` (rev 2 — Paraglide). Decisions D1–D5 from §13 assumed approved.

## Task 4: LanguageSwitcher component

**Files:**
- Create: `src/lib/components/Landing/LanguageSwitcher.svelte`

Native-label dropdown modeled on the reference repos' switcher, restyled gold-on-green. `setLocale(code)` persists to `localStorage` and reloads (Paraglide default), so all `m.*()` re-render in the new locale.

- [ ] **Step 1: Create `src/lib/components/Landing/LanguageSwitcher.svelte`**

```svelte
<!-- src/lib/components/Landing/LanguageSwitcher.svelte -->
<script lang="ts">
  import { locales, getLocale, setLocale } from '$lib/paraglide/runtime';
  import * as m from '$lib/paraglide/messages';
  import { ChevronDown } from '@lucide/svelte';

  // Paraglide's generated runtime is JS (no exported `Locale` type) — derive the
  // union from the `locales` value tuple (Nasab pattern). If svelte-check rejects
  // this, fall back to: import { type locales as LocalesTuple } ...; type Locale = (typeof LocalesTuple)[number];
  type Locale = (typeof locales)[number];

  const NATIVE: Record<string, string> = { en: 'English', ms: 'Bahasa Melayu', id: 'Bahasa Indonesia' };

  let open = $state(false);
  let current = $state<Locale>(getLocale());
  $effect(() => { current = getLocale(); });

  function choose(l: Locale) {
    open = false;
    if (l !== current) setLocale(l); // persists to localStorage + reloads
  }

  $effect(() => {
    if (!open) return;
    const onDoc = (e: MouseEvent) => { if (!(e.target as Element).closest('.lang-switch')) open = false; };
    document.addEventListener('click', onDoc);
    return () => document.removeEventListener('click', onDoc);
  });
</script>

<div class="lang-switch relative">
  <button
    type="button"
    onclick={() => (open = !open)}
    aria-label={m.header_language()}
    aria-expanded={open}
    class="flex items-center gap-1.5 px-2.5 py-1.5 rounded border border-gold/25 text-gold/80 hover:text-gold hover:border-gold/50 transition-colors"
    style="font-family:'Raleway',sans-serif"
  >
    <span class="text-xs uppercase tracking-wider">{NATIVE[current]}</span>
    <ChevronDown class="w-3.5 h-3.5 transition-transform {open ? 'rotate-180' : ''}" />
  </button>

  {#if open}
    <div class="absolute right-0 top-full mt-1 w-44 rounded-lg border border-gold/20 bg-surface shadow-xl overflow-hidden z-50">
      {#each locales as l}
        <button
          type="button"
          onclick={() => choose(l)}
          aria-current={l === current ? 'true' : undefined}
          class="w-full px-4 py-2.5 text-left text-sm transition-colors {l === current ? 'bg-gold/15 text-gold' : 'text-white/70 hover:bg-white/5 hover:text-gold'}"
          style="font-family:'Raleway',sans-serif"
        >{NATIVE[l]}</button>
      {/each}
    </div>
  {/if}
</div>
```

> NOTE: `locales`/`getLocale`/`setLocale` are generated by Paraglide in `src/lib/paraglide/runtime` (JS — there is no exported `Locale` type, so it's derived from the `locales` value above). `@lucide/svelte` is already a dependency (Svelte 5).
